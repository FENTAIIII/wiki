按现象排障

先找最像你的现象，只做对应检查。

报错找不到 dist/noname.js​

只检查这一条完整路径是否存在：

你的服务端/plugins/Sanguo/noname/dist/noname.js

然后检查：

rules:
  noname-root: "noname"

不要填写桌面路径，不要把 noname 放到 plugins 外面。

报错找不到 Node​

在服务端电脑的终端执行：

node --version

必须能直接输出 v24 或更高版本。提示“不是内部或外部命令”时，需要安装 Node.js， 并在安装后重新打开终端或重启面板。

报错找不到浏览器​

Windows 安装 Chrome 或 Edge，rules.browser 先保持空字符串。Linux 面板服安装 Chromium 后，在 rules.browser 填服务商提供的可执行文件路径。

已找到浏览器但报错 Chrome failed to start​

这是 Noname 后端的浏览器运行环境问题，不是三国杀出牌逻辑问题。

如果日志已经显示 Node.js 版本，并在随后出现：

Error: Chrome failed to start
Noname sidecar exited unexpectedly

说明 Node.js、noname-root 和 dist/noname.js 已经通过前置检查，但是 Chrome 或 Edge 刚启动就退出了。

Windows 解决方法​

  1. 完整关闭服务端；
  2. 安装或修复最新版 64 位 Chrome，并手动打开一次后关闭；
  3. 打开 plugins/Sanguo/config.yml；
  4. 在 rules 下明确填写实际存在的浏览器路径；
  5. 完整重启服务端，不能只执行插件重载。

Chrome 默认路径：

rules:
  browser: "C:/Program Files/Google/Chrome/Application/chrome.exe"

如果电脑只安装了 Edge，依次检查下面两个路径，填写实际存在的一个：

rules:
  browser: "C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe"
rules:
  browser: "C:/Program Files/Microsoft/Edge/Application/msedge.exe"

建议在 YAML 中使用 /，避免 Windows 路径中的反斜杠被错误转义。

仍然无法启动​

在服务端电脑的 PowerShell 中执行：

& "C:\Program Files\Google\Chrome\Application\chrome.exe" --version
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --remote-debugging-port=9222 --user-data-dir="$env:TEMP\sanguo-chrome-test" about:blank

如果使用 Edge，把命令开头替换成实际的 msedge.exe 路径。

第二条命令如果立即退出或显示错误，检查：

  • 服务端运行账号是否有权写入系统临时目录；
  • 安全软件是否拦截无界面浏览器；
  • Chrome/Edge 是否安装完整、版本是否过旧；
  • Windows 系统是否仍受当前浏览器版本支持。

向维护人员反馈时，请提供这两条命令的完整输出、Windows 版本、浏览器版本和 rules.browser 的实际填写值。不要发送账号密码或其他敏感配置。

日志中的 %E6%... 等内容只是中文路径经过 URL 编码后的正常显示，不是乱码， 也不是此错误的直接原因。此时不需要重装 Java、Node.js 或 Sanguo。

修复成功后，启动日志中不再出现 Chrome failed to start，并会出现：

[Sanguo] Noname rules runtime connected

玩家无法加入​

检查：

  • CraftEngine 和 BetterHUD 是否正常启用；
  • 是否安装 GSit 或 CMI；
  • 玩家是否有 sanguo.play；
  • 牌桌是否已经开始或坐满；
  • 经济桌余额是否足够；
  • 玩家是否已经坐在另一张桌。

牌、武将或按钮显示方框​

这是资源包问题，不是 Noname 规则问题：

  1. CraftEngine 的两个 Sanguo 资源目录是否完整；
  2. CraftEngine 是否成功构建资源包；
  3. 客户端是否接受并加载资源包；
  4. 服务端是否完整重启。

准星没有说明​

这是 BetterHUD 链路：

  • 检查三个 BetterHUD 子目录是否已合并；
  • 检查 crosshair_text_hud 是否加入服主使用的 HUD；
  • 看 BetterHUD 控制台是否有格式错误；
  • 执行 /sanguo reload 后重新加入牌桌。

选中牌又弹回​

  • 看 Actionbar 是否要求选择角色；
  • 检查目标是否在距离内；
  • 确认当前是自己行动；
  • 无中生有、装备、闪电不需要选其他角色；
  • 杀、顺手牵羊等需要合法目标。

如果按钮全部消失且双方一直等待，保存控制台从卡住前 30 秒到卡住后的日志，并记录：

  • 牌名；
  • 当前玩家武将；
  • 点击顺序；
  • 真人数量和 AI 数量。

黄盖苦肉后要求弃牌​

技能点击后应直接失去 1 点体力并摸 2 张。如果是在回合结束前进入弃牌阶段， 通常是因为手牌超过降低后的体力上限，属于正常规则；标准黄盖本身没有弃牌步骤。

铁索连环怎么重铸​

先点“重铸”，再选铁索连环，最后确定。先选择铁索连环会进入普通使用流程。

经济被冻结​

不要删除 wager-transactions.log。对照 Vault/PlayerPoints 流水，核对悬空 INTENT 或没有 MATCH_CLOSED 的局，再人工处理。

# 命令与权限

插件 `NongStoveIgniter` 的全部命令都在 `/ng` 之下，别名 `/nong`。

## 玩家命令

这些命令**不需要权限**，所有玩家都能用：

| 命令 | 作用 |
| --- | --- |
| `/ng` 或 `/ng help [页码]` | 显示帮助，共 2 页 |
| `/ng recipes` | 打开配方总菜单，按设备分五类浏览 |
| `/ng pot recipes` | 烹饪锅配方浏览器 |
| `/ng skillet recipes` | 煎锅配方浏览器 |
| `/ng cut recipes` | 砧板配方浏览器 |
| `/ng cask recipes` | 小木桶配方浏览器 |
| `/ng stomping recipes` | 木盆配方浏览器 |

`recipes` 可以简写为 `recipe` 或 `r`。

:::warning
`/ng skillet` 和 `/ng cut` **不带参数时会走管理界面分支**，普通玩家会被拒绝。让玩家用 `/ng skillet recipes` 这种完整写法，或直接用 `/ng recipes`。
:::

## 管理员命令

| 命令 | 权限 | 作用 |
| --- | --- | --- |
| `/ng pot gui` | `nong.pot.admin` | 烹饪锅配方管理界面 |
| `/ng skillet gui` | `nong.skillet.admin` | 煎锅配方管理界面 |
| `/ng cut gui` | `nong.cuttingboard.admin` | 砧板配方管理界面 |
| `/ng cask gui` | `nong.cask.admin` | 小木桶配方管理界面 |
| `/ng stomping gui` | `nong.stomping.admin` | 木盆配方管理界面 |
| `/ng reload` | 任意一个子权限 | 重载全部配方 |
| `/ng <设备> reload` | 对应子权限 | 同样是全量重载 |
| `/ng recipes import-farmers-delight` | `nong.admin` | 导入 FD 砧板配方 |

## 权限

| 权限 | 默认 | 说明 |
| --- | --- | --- |
| `nong.admin` | op | 总管理员，包含下面全部子权限 |
| `nong.pot.admin` | op | 烹饪锅 |
| `nong.skillet.admin` | op | 煎锅 |
| `nong.cuttingboard.admin` | op | 砧板 |
| `nong.cask.admin` | op | 小木桶 |
| `nong.stomping.admin` | op | 木盆 |

拥有 `nong.admin` 等于拥有全部子权限。

## 重载的范围

`/ng reload` 重载的是 **`recipes.yml`** —— 读取、解码、编译、发布五类设备的新配方快照。成功时会报出各类数量。

要点：

- **各设备的 `reload` 子命令实际都是全量重载**，没有单设备粒度，区别只在权限检查项。
- **校验失败会整体回滚**：不发布新快照，保留原有配方，并输出诊断信息。这意味着写坏了配方不会导致线上配方消失。
- **不会重载 `config.yml`**，也**不会重载 `recipe_gui.yml`**。改这两个文件需要重启服务器。

## 导入 Farmers Delight 砧板配方

```
/ng recipes import-farmers-delight
```

插件内建 **61 条** `fd-*` 前缀的砧板配方（树皮、竹篮、黏土与沙砾、稻穗、熟肉、野生作物、花朵染料等），但**默认不启用**，需要管理员主动执行这条命令导入。

行为说明：

- 只对 `recipes.yml` 的 `cutting-board` 分区做 **`putIfAbsent`**：同 ID 已存在则跳过，**绝不覆盖**你已有的配方。
- 合并后整体校验再原子写回，失败时 `recipes.yml` 不被修改。
- 成功时提示新增了几条、跳过了几条。
- 因为是「只补不覆盖」，普通的 `/ng reload` **不会**把你删掉的 fd 配方恢复回来。

## 依赖关系

| 插件 | 类型 | 说明 |
| --- | --- | --- |
| CraftEngine | **必需** | 所有自定义方块、家具、物品的基础 |
| UltimateAdvancementAPI | 可选 | 缺失时成就系统不工作 |
| MMOItems | 可选 | 支持配方使用 MMOItems 物品 |
| CustomFishing | 可选 | 支持配方匹配 CustomFishing 鱼类 |

:::note
即使不打算用 CustomFishing 的鱼，只要服务器装了它就应保留软依赖声明，否则加载顺序可能导致鱼类物品匹配静默失效。
:::

# 配置说明

插件有两个配置文件，都在 `plugins/NongStoveIgniter/` 下。

:::warning
这两个文件**都不支持热重载**。`/ng reload` 只重载 `recipes.yml`。改配置需要重启服务器。
:::

## config.yml

### 炉灶方块

```yaml
stove-blocks:
  - default:stove
  - endersdelight:endstone_stove
```

哪些 CraftEngine 自定义方块算作炉灶（可被点燃、可作为烹饪锅与煎锅的热源）。

这些方块**必须带有 `lit(boolean)` 与 `facing(4-direction)` 属性**，否则点火会失败并在日志里告警。留空时使用内置默认值。

### 紫色火焰 / 高级炉灶

```yaml
purple-flame-blocks:
  - endersdelight:endstone_stove
```

这个列表有两层含义：

1. **视觉**：燃烧时使用末地紫色火焰粒子（染色 DUST），而不是默认橙色。
2. **机制**：列在这里的炉灶同时被视为「**高级炉灶**」——只接受金煎锅系列，普通煎锅放上去不会加热。

另外，高级炉灶必须用**龙息**点燃而不是打火石。列在这里的方块**必须同时出现在 `stove-blocks` 中**才能被点燃。

### 砧板家具

```yaml
cutting-board-blocks:
  - default:cutting_board
  - zhanban:oak_cutting_board
  # ... 共 49 个 zhanban 木种
```

哪些 CraftEngine 家具算作砧板。这是**软注册**：

- 只按 id 识别，插件**不强制依赖** `zhanban` 资源包。
- 没装该包时对应家具不会生成，列表里多余的 id **不会造成任何影响**。
- 要加自定义木种砧板，把家具 id 追加到列表即可，不需要改代码。

### 成就开关

```yaml
advancements-enabled: true
advancements:
  farmers-delight-enabled: true
  end-delight-enabled: true
```

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `advancements-enabled` | `true` | **总开关**。`false` 时完全关闭：不注册、不监听、不发放 |
| `advancements.farmers-delight-enabled` | `true` | 单独控制「农夫乐事」成就页 |
| `advancements.end-delight-enabled` | `true` | 单独控制「末地乐事」成就页 |

单页开关**只在总开关为 `true` 时有效**。总开关为 `false` 时两页都关闭。

### 浇水壶肥料消耗

```yaml
watering-can:
  fertilizer-per-block: false
```

控制主手浇水壶 + 副手骨粉/粪肥右键耕地时的肥料消耗方式。该操作对 **3×3 共 9 格**作物催熟。

| 值 | 行为 | 性价比 |
| --- | --- | --- |
| `false`（默认） | 一次施肥固定消耗 **1 个**肥料 | 是肥料袋与洒水器的 **9 倍** |
| `true` | 每成功催熟 1 格消耗 1 个肥料 | 与其他施肥途径一致 |

两种设置都**只在至少有一格成功催熟时才扣肥料**，对石头或已成熟作物使用不会浪费。

:::tip 平衡性建议
默认值 `false` 让浇水壶明显强于其他施肥手段。如果你的服务器希望三种施肥途径性价比接近，把它改成 `true`。
:::

### 金煎锅系列（不可配置）

金煎锅的档位写死在代码里，`config.yml` 里只有说明性注释：

| 煎锅 | 速度 | 说明 |
| --- | --- | --- |
| `endersdelight:skillet_gold` | 最快 | 净锅 |
| `endersdelight:skillet_cracked` | 略慢 | 带油渍 |
| `endersdelight:skillet_damaged` | 更慢 | 油污 |
| `endersdelight:skillet_broken` | 不可用 | 重油垢，只能熔炼成 1 金锭 |

金煎锅每累计煎熟 **16 件**成品自动降一档（家具自动替换，保留正在煎的食物）。用肥皂可以逆向清洗。

## recipe_gui.yml

只控制**玩家 `/ng recipes` 配方浏览界面**的外观：五类配方列表标题、配方详情标题、翻页与返回按钮的物品。

不影响管理员配方管理界面、配方编辑器、按钮槽位、按钮名称、Lore 或点击行为。

### 结构

```yaml
defaults:
  # list-title: 统一的列表标题（默认注释掉）
  # view-title: 统一的详情标题（默认注释掉）
  buttons:
    previous:
      item: minecraft:arrow
      fallback-material: ARROW
    previous-disabled:
      item: minecraft:gray_dye
      fallback-material: GRAY_DYE
    next:
      item: minecraft:arrow
      fallback-material: ARROW
    next-disabled:
      item: minecraft:gray_dye
      fallback-material: GRAY_DYE
    return-menu:
      item: minecraft:book
      fallback-material: BOOK
    return-list:
      item: default:page_backward
      fallback-material: ARROW

categories:
  cooking-pot:
    list-title: 烹饪锅配方
    view-title: '<shift:-8><white><image:nong:cooking_pot_gui>'
    gold-view-title: '<shift:-8><white><image:endersdelight:cooking_pot_gold_gui>'
    buttons: {}
  skillet:
    list-title: 煎锅配方
    view-title: '<shift:-8><white><image:nong:cutting_skillet_gui>'
  cutting-board:
    list-title: 砧板配方
  stomping-basin:
    list-title: 木盆配方
  cask:
    list-title: 小木桶配方
```

### 六个导航按钮

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `previous` | `minecraft:arrow` | 可翻上一页 |
| `previous-disabled` | `minecraft:gray_dye` | 已是第一页 |
| `next` | `minecraft:arrow` | 可翻下一页 |
| `next-disabled` | `minecraft:gray_dye` | 已是最后一页 |
| `return-menu` | `minecraft:book` | 返回配方总菜单 |
| `return-list` | `default:page_backward` | 返回当前分类列表 |

### 规则

- 分类键固定为 `cooking-pot`、`skillet`、`cutting-board`、`stomping-basin`、`cask`。
- 只有 `cooking-pot` 支持额外的 `gold-view-title`（金锅详情专用标题）。
- `buttons: {}` 表示全部继承 `defaults.buttons`，也可以只覆盖某一个按钮。
- 物品 id **必须带命名空间**：`minecraft:arrow` 或 `default:page_backward`，不能只写 `ARROW`。
- CE 物品不存在或构建失败时回退到 `fallback-material`（须为合法 Bukkit Material 名）。
- 标题支持普通文字，也支持 CraftEngine 的 MiniMessage 图片标签。
- 配置损坏、字段格式错误或物品无法创建时，会回退到内置默认外观并在日志里告警。

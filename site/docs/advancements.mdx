# 成就一览

整合内容提供三个独立成就页：**农夫乐事**、**末地乐事**与**蟹农乐事**。打开原版成就界面就能看到它们，根成就会自动解锁。

大部分成就是**持有即得**：物品进背包就会自动检测发放，不需要特意做什么。

## 农夫乐事

### 作物线

| 成就 | 类型 | 条件 |
| --- | --- | --- |
| 野性生长 | 任务 | 获得卷心菜种子、番茄种子、洋葱或稻米中的任意一种 |
| 水田之间 | 任务 | 种下一株稻米 |
| 蔬果满园 | **挑战** | 种下全部 19 种主要作物 |
| 菌丝成群 | 任务 | 获得棕色或红色蘑菇菌落 |
| 嘘！去！ | 任务 | 用烂番茄砸中袭击者 |
| 采田艹加 | 任务 | 从绳子上收获成熟番茄 |

**蔬果满园**需要的 19 种作物（注意是**种下**，不是收获）：

小麦、甜菜根、胡萝卜、马铃薯、西瓜、南瓜、甜浆果、甘蔗、海带、可可豆、下界疣、紫颂花、棕色蘑菇、红色蘑菇、发光浆果、卷心菜、番茄、洋葱、稻米。

:::tip
前 15 种是原版作物，随便找块地依次种一遍即可。后 4 种是整合内容的自定义作物，需要先在野外找到野生版本，见[作物与野外采集](/farming/crops)。
:::

### 烹饪线

| 成就 | 类型 | 条件 |
| --- | --- | --- |
| 架起炉火 | 任务 | 放置营火或灵魂营火 |
| 平底锅登场 | 任务 | 放置煎锅 |

| 一锅好菜 | 任务 | 放置烹饪锅 |

**大厨之路**需要**吃掉**的 25 道菜：

培根鸡蛋、烘焙鳕鱼炖、牛肉炖、大骨汤、鸡肉汤、米饭、鱼肉炖、炒饭、微光沙拉、香烤鲑鱼、蜜汁火腿、混合沙拉、蘑菇饭、面条汤、肉丸意面、羊排意面、南瓜汤、蔬菜杂烩、烤羊排、牧羊人派、鱿鱼墨面、牛排配土豆、填馅南瓜、蔬菜面、蔬菜汤。

这些几乎全部来自[烹饪锅](/stations/cooking-pot)。

## 末地乐事

| 成就 | 类型 | 条件 |
| --- | --- | --- |
| 末地灶台 | 任务 | 获得末地石炉灶 |
| 紫焰燃起 | 任务 | 用龙息点燃末地石炉灶 |
| 黄金之锅 | **目标** | 获得金烹饪锅 |
| 自制肥皂 | 任务 | 获得任意一种肥皂 |
| 黄金煎锅 | 任务 | 获得金煎锅 |
| 锃亮如新 | **目标** | 用肥皂把脏煎锅洗成金煎锅 |
| 至臻洁净 | **目标** | 获得下界合金肥皂 |
| 螨壳收集 | 任务 | 获得末影螨壳 |
| 凝视之眼 | 任务 | 获得末影人眼球 |
| 庖丁解眼 | 任务 | 在砧板上切开末影人眼球 |
| 末地农耕 | 任务 | 获得一种末地作物 |
| 初尝末地 | 任务 | 品尝任意一道末地料理 |
| 末地乐事 | **挑战** | 尝遍 15 种末地料理 |

**肥皂**共 9 种：普通、煤炭、铁、铜、青金石、金、钻石、绿宝石、下界合金。

**末地作物**共 4 种：琥珀竹荪、虚空辣椒、空灵藏红花、紫颂焰。

**末地乐事**需要吃掉的 15 道菜包括：填馅潜影贝、紫颂炖、缠怨麦片、末影螨炖、珍珠意面、末影海鲜饭、琥珀竹荪炖、琥珀竹荪咖喱、鸡肉咖喱、牛排配薯条、竹荪烩饭等。

:::note
大部分末地料理需要[金烹饪锅](/stations/cooking-pot#金烹饪锅末地乐事)才能制作，并且要用潜影贝碗作容器。
:::

## 蟹农乐事

根成就**蟹农乐事**（一场海鲜冒险在等着你！）自动解锁，其下共 8 个成就。

| 成就 | 类型 | 条件 |
| --- | --- | --- |
| 这是个蟹阱！ | 任务 | 用绳子、台阶和木棍来制作你的第一个捕蟹笼 |
| 美丽的珍珠之母啊！ | 任务 | 在砧板上剖开蛤蜊，获得第一颗珍珠 |
| 甲壳动物烹饪站 | 任务 | 将螃蟹、虾和龙虾用厨锅煮熟（3 个子任务） |
| 虾炒饭？！ | **挑战** | 获得虾炒饭 |
| 手可摘海星！ | **目标** | 获得一个蟹钳来延长你的触及距离 |
| 深洋杀手 | 任务 | 用刀从鱿鱼身上切下鱿鱼须 |
| 渊洋杀手 | **目标** | 用刀从发光鱿鱼身上切下发光鱿鱼须 |
| 尝起来像鸡肉 | 任务 | 用刀从青蛙身上切下青蛙腿 |

成就树的父子关系：**这是个蟹阱！** 是三条主线的起点，**美丽的珍珠之母啊！**、**甲壳动物烹饪站**、**虾炒饭？！** 都挂在它下面。**渊洋杀手**需要先完成**深洋杀手**。其余成就直接挂在根成就上。

**甲壳动物烹饪站**是多任务成就，需要分别获得熟螃蟹、熟虾、熟龙虾三种，集齐才算完成。

:::tip
蟹农页的全部成就都是**持有即得**：插件每 10 秒扫描一次背包，检测到对应物品就发放。所以「用刀切下鱿鱼须」这类描述实际只要**拿到**鱿鱼须就会解锁，不要求亲手切。
:::

## 成就没出现？

- 成就系统可以被管理员整体或分页关闭，见[配置说明](/admin/config)。
- 持有类成就在**物品进背包**时检测，如果没触发试着把物品拿出来再放回去。蟹农页额外有 10 秒一次的定时扫描，等一会儿也会补发。
- 三个成就页都依赖服务器安装 UltimateAdvancementAPI。缺这个插件时成就页不会注册，但不影响其他玩法。
- 「大厨之路」和「末地乐事」的子任务会自动跳过服务器上不存在的物品，所以实际需要的道数可能少于列表。

# FAQ

## 这个 GitHub 仓库会公开插件源码吗？

不会。Wiki 只托管使用文档。插件仍然是闭源付费插件。

## 没有 GSit 或 CMI 能玩吗？

能。坐下姿态会降级，但斗地主核心玩法仍可运行。

## 没有 Vault 能玩吗？

能。休闲桌不需要 Vault。只有全局游玩费和单桌欢乐豆赌局需要 Vault Economy。

## 可以只开某几张桌为赌桌吗？

可以。使用：

```text
/ddz economy <桌名> on [倍率]
```

未开启的桌都是休闲桌。

## 玩家中途离开会怎样？

默认配置下，局内 `/ddz leave` 会转为托管，本局继续结算。你也可以把 `player-session.leave-trustee` 改为 `false`，让局内退出立即判负。

## 癞子能变王吗？

不能。癞子只能替代 `3..2`，不能替代大小王。

## 单张癞子是不是可以当任意单牌？

不是。单独出一张癞子时，按它原本的实体牌点处理。

## 旁观者能看到玩家手牌吗？

由 `game.spectator-show-all` 控制。但欢乐豆牌桌始终不会向旁观者展示私牌。

## 排行榜占位符需要额外下载扩展吗？

不需要。插件内置 PlaceholderAPI 扩展，安装 PlaceholderAPI 本体即可。

## 为什么经济牌局要求每个人都有 2 倍赌注？

叫地主前无法知道谁是地主。地主最大可能输 2 倍，所以每个人开局前都按最大责任托管，确保结算时不会因为余额变化导致赖账。

## 可以把牌皮做成付费内容吗？

可以。给牌皮配置独立权限，例如 `doudizhu.skin.premium`，再通过权限插件或商城插件发放。

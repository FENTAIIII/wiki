# 玩家游玩指南

## 加入与离开

加入指定牌桌：

```text
/ddz join <桌名>
```

加入附近牌桌：

```text
/ddz join
```

离开牌桌：

```text
/ddz leave
```

如果还没开局，离开就是普通退座。如果已经开局，行为取决于 `config.yml` 的 `player-session.leave-trustee`：

- `true`：离开后进入托管，本局继续结算。
- `false`：立即结束本局，退出者按地主败北处理。

## 叫地主

开局后随机一名玩家先叫地主。之后三名玩家依次选择：

- 不叫
- 叫地主
- 抢地主

最后一个选择叫/抢的人成为地主。三个人都不叫时，系统重新洗牌发牌。

## 出牌

轮到自己时，点击手牌选择，再点击出牌按钮。插件会自动判断牌型是否合法、是否能压过上家。

可以点击不出，但新一轮首出者不能不出。

## 提示与要不起

如果当前没有能压过上家的牌，插件会提示无可压牌。配置中存在 `no-beat-timeout` 和 `no-beat-opponent-timeout`，用于在玩家确定要不起时仍保留短暂操作时间，同时避免旁观者直接看出手牌状态。

## 催促

使用：

```text
/ddz urge
```

会催促当前行动玩家。催促有冷却，默认 `10` 秒。文案可在 `config.yml` 的 `urges` 中修改。

## 托管与回桌

主动托管：

```text
/ddz trustee
```

回到桌边后取消托管：

```text
/ddz return
```

托管适用于玩家临时离开、掉线、离开牌桌范围等情况。本局仍会正常进行和结算。为防止刷状态，托管切换有冷却，默认 `2000` 毫秒。轮到托管座位时，插件至少等待 3 秒，让玩家有机会取消托管。

## 牌皮

查看当前牌皮和可用牌皮：

```text
/ddz skin
```

切换牌皮：

```text
/ddz skin <牌皮ID>
```

恢复默认：

```text
/ddz skin reset
```

牌皮通常需要 CraftEngine 与对应资源包。没有可用资源包时，牌面会回退到普通文字显示。

---
title: 山茶花与制茶
sidebar_position: 4
---

山茶花是一套围绕茶的玩法，由 `camellia` 命名空间提供：种植茶树收茶叶，用不同方块工序加工成六种茶叶，再放进茶壶煮水泡茶。

整条链路分三步：**种茶收叶 → 加工工序 → 茶壶煮制**。草药茶跳过加工，直接把花草丢进茶壶。

## 茶树

`camellia:tea_crop` 是四阶段作物，只能种在**耕地**上。

| 属性 | 数值 |
| --- | --- |
| 生长阶段 | 4 段（age 0 到 3） |
| 生长速度 | 0.25 |
| 需要光照等级 | 9 |
| 骨粉 | 可用，每次 +1 阶段 |

任意阶段收割都掉 **1 个茶叶**。长到成熟阶段（`age=3`）时额外多掉一份，并且这一份**吃时运加成**。

### 嗅探兽

嗅探兽挖出**火把花种子**或**酢浆草荚**时，有 **1/3** 概率把掉落替换成同数量的茶叶。只有这两种原版挖掘产物会被替换，其他掉落不受影响。

## 茶叶加工

手持茶叶**潜行右键**特定方块即可施加一道工序。每片茶叶记录自己的工序历史，最多 **7 道**。

| 工序 | 方块 |
| --- | --- |
| 揉捻 | 工作台 |
| 萎凋 | 营火 / 灵魂营火 |
| 干燥 | 脚手架 |
| 渥堆 | 湿海绵 |

:::note
渥堆会把湿海绵变成干海绵，需要重新泡水才能再用。
:::

配方按**完整工序列表精确匹配**，顺序不同就是不同的茶，也允许重复同一道工序。六种茶叶配方：

| 成品 | 工序顺序 |
| --- | --- |
| 白茶 | 萎凋 → 干燥 |
| 绿茶 | 干燥 |
| 乌龙茶 | 干燥 → 揉捻 → 萎凋 |
| 红茶 | 干燥 → 萎凋 |
| 生普洱茶 | 萎凋 → 揉捻 → 干燥 → 揉捻 |
| 熟普洱茶 | 萎凋 → 揉捻 → 干燥 → 渥堆 → 干燥 |

工序做错或凑不成任何配方的茶叶无法在茶壶里煮出茶，投料时会直接被拒绝。

### 草药茶

四种草药茶不走工序，把材料直接投进茶壶就行：

| 成品 | 可用材料 |
| --- | --- |
| 洋甘菊茶 | 滨菊 |
| 薰衣草茶 | `natures_spirit:lavender`、`nomansland:lavender_bush`、绵球葱 |
| 洛神花茶 | `natures_spirit:hibiscus`、红色郁金香 |
| 薄荷茶 | `nomansland:wild_mint`、蕨 |

其中带命名空间的是其他模组的花草，同一种茶的多个材料等效。

## 茶壶

<RecipeFor item="camellia:teapot" />

茶壶是家具，放好后按顺序主手右键操作：

1. **加水**：手持水桶或水瓶右键。水桶换成空桶，水瓶换成玻璃瓶。
2. **投料**：右键放入 1 个茶叶或草药，只能放一份。
3. **加热**：茶壶需要待在热源上，煮制期间会冒白烟粒子。
4. **取茶**：煮好后手持**玻璃瓶**右键，得到 1 瓶茶。

煮好瞬间会有一圈粒子和酿造台音效提示。

### 时间与过度冲泡

计时**只在热源满足时推进**，移开热源就暂停。

| 阶段 | 时间 |
| --- | --- |
| 煮好可取 | 200 tick（10 秒） |
| 变成过度冲泡的茶 | 400 tick（20 秒） |

超时后播放灭火音效，此时取出的只能是**过度冲泡的茶**，且计时停止不再变化。

### 热源

茶壶**所在方块或正下方方块**任一为热源即可。

| 一直有效 | 需要点燃 |
| --- | --- |
| 岩浆、岩浆块 | 熔炉、高炉、烟熏炉、营火、灵魂营火、[炉灶](/stations/stove) |

:::tip
茶壶被破坏时，里面已投入的茶材会掉落回来，不会白扔。煮制进度会随存档保存，区块重新加载后继续。
:::

## 饮用效果

所有茶都用蜜糖瓶做基底，属性一致：饱食度 **1**、饱和度 **2.0**，**饱腹时也能喝**，喝完 **1.6 秒**并返还玻璃瓶。

各茶的额外效果都是**等级 I**：

| 茶 | 效果 | 持续 |
| --- | --- | --- |
| 白茶 | 生命恢复 | 340 tick（17 秒） |
| 绿茶 | 急迫 | 300 tick（15 秒） |
| 乌龙茶 | 跳跃提升 | 200 tick（10 秒） |
| 红茶 | 迅捷 | 400 tick（20 秒） |
| 洋甘菊茶 | 生命恢复 | 180 tick（9 秒） |
| 薰衣草茶 | 村庄英雄 | 300 tick（15 秒） |
| 洛神花茶 | 伤害吸收 | 300 tick（15 秒） |
| 薄荷茶 | 水下呼吸 | 400 tick（20 秒） |
| 过度冲泡的茶 | 反胃 | 200 tick（10 秒） |

**生普洱茶**和**熟普洱茶**没有额外药水效果，只有上面那套统一食物属性。

过度冲泡的茶除了反胃，还会把玩家的**失眠计时清零**，等于消掉幻翼的刷出条件。喝坏茶反而能防幻翼。

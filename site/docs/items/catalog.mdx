# 物品图鉴

按游戏内物品浏览器的分类列出全部物品。标注**可合成**的物品在[合成表](/recipes/crafting)里能找到配方，其余物品来自烹饪设备、野外采集或掉落。

:::tip
悬停可以看到完整的命名空间 id。搜索框支持中文名与 id。
:::

# 工作台合成表

工作台配方共 **93 条**：有序合成 44 条、无序合成 49 条。熔炉、烟熏炉与营火配方见[熔炉与营火配方](/recipes/cooking)。

## 怎么看配方图

- 左侧 3×3 网格是**有序合成**的摆放位置，斜纹格子表示该位置必须留空。
- 无序合成只显示材料列表，摆放位置任意。
- 格子右下角有数字时，表示这一格有多个可替换材料，图标会轮流展示；鼠标悬停可以看到完整列表，配方下方的「可替换材料」也会列出。
- 配方图下方列出每种材料的名称与用量。
- 物品标签（如任意木板）的图标会循环展示可用的木种。

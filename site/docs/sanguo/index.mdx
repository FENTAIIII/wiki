# Sanguo 三国杀

Sanguo 把真实的 Noname 三国杀规则运行在服务端，再把牌、武将、身份、装备、判定区和
操作按钮显示成 Minecraft 里的实体牌桌。

## 已支持的模式

- **三人斗地主**：使用三国杀卡牌和武将进行三人斗地主。
- **五人身份局**：主公、忠臣、反贼、内奸。
- **八人身份局**：完整八人经典身份场。

至少要有一名真人，空位可以用 AI 补齐。牌桌坐满后会自动进入选将。

## 操作特点

- 所有牌、武将、角色和按钮都用**右键**操作，左键不操作 UI。
- 选中的内容会出现黄色框，再点一次可以取消。
- 出牌时看屏幕下方 Actionbar，它会告诉你还差几张牌、几个目标。
- 每名玩家只能看到自己的手牌和应当公开的信息。
- 标准黄盖的苦肉是失去 1 点体力并摸 2 张牌，不需要弃牌；回合末超过手牌上限时仍会
  按通用规则弃牌。

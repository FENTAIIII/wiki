# 模式与规则

Sanguo 不在 Kotlin 里重写一套“差不多”的规则，而是让 Noname 负责卡牌合法性、
技能事件、距离、目标和结算。Minecraft 端负责显示与输入。

## 三国斗地主

- 三人参与；
- 身份为一名地主、两名农民；
- 使用三国杀武将、手牌和技能；
- 地主与农民按 Noname 该模式的胜负条件结算。

创建命令：

```text
/sanguo create doudizhu <桌名>
```

## 五人身份局

五名角色组成精简身份场，包含主公、忠臣、反贼与内奸。身份是否公开由规则状态决定，
未公开时其他玩家只看到“猜”。

```text
/sanguo create identity5 <桌名>
```

## 八人身份局

完整经典身份场，支持八个物理座位、完整角色区和结算界面。

```text
/sanguo create identity8 <桌名>
```

## 当前卡牌和武将

- 武将包：标准包；
- 卡牌包：标准包、军争扩展；
- 武将可由权限节点控制；
- 对手暗置手牌不会因为顺手牵羊或过河拆桥而泄露牌面。

## 几条容易误解的规则

### 标准黄盖不是界黄盖

标准黄盖的苦肉是失去 1 点体力并摸 2 张牌，技能发动时不弃牌。体力减少后，回合末
手牌超过当前体力上限，仍然需要按通用弃牌阶段弃牌。

### 铁索连环可以重铸

从操作区先选“重铸”，再选择铁索连环。直接选择铁索连环是把它当锦囊使用，不是重铸。

### 顺手牵羊看不到对手手牌牌面

随机获得对手手牌时只显示暗置牌背；装备区等公开区域照常显示。

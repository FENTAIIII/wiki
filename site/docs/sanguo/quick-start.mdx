# 五分钟开第一桌

## 1. 找一块空地

准备至少 5×5 的平整地面。把准星对准你想作为牌桌中心的地板方块。

## 2. 创建牌桌

三人斗地主：

```text
/sanguo create doudizhu test
```

五人身份局：

```text
/sanguo create identity5 test
```

八人身份局：

```text
/sanguo create identity8 test
```

`test` 是牌桌名，可以换成中文、英文、数字、下划线或短横线。

## 3. 玩家加入

玩家输入：

```text
/sanguo join test
```

站在牌桌附近时也可以不写桌名：

```text
/sanguo join
```

## 4. 用 AI 补空位

每执行一次增加一名 AI：

```text
/sanguo ai test
```

至少保留一名真人。经济牌桌不能加 AI。

## 5. 开始

坐满后会自动开局。没有自动开始时执行：

```text
/sanguo start test
```

进入选将界面后：

1. 右键武将，出现黄色框；
2. 再次右键同一个武将，确认选择；
3. 不满意可以右键“换一批”；
4. 不想选可以右键“AI 帮选”。

## 6. 第一次验收

- 每个人只看到自己的手牌；
- 右键手牌后有黄色选择框；
- 需要目标的牌会让合法角色变为可选；
- 无中生有、装备、闪电等不需要选择其他玩家；
- Actionbar 会提示下一步；
- 开局有背景音乐，出牌、技能和扣血有相应声音。

完成后可以看[玩家游玩指南](./player-guide)或[命令与权限](./commands-and-permissions)。

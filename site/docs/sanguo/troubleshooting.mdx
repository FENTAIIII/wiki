# 按现象排障

先找最像你的现象，只做对应检查。

## 报错找不到 `dist/noname.js`

只检查这一条完整路径是否存在：

```text
你的服务端/plugins/Sanguo/noname/dist/noname.js
```

然后检查：

```yaml
rules:
  noname-root: "noname"
```

不要填写桌面路径，不要把 `noname` 放到 `plugins` 外面。

## 报错找不到 Node

在服务端电脑的终端执行：

```text
node --version
```

必须能直接输出 v24 或更高版本。提示“不是内部或外部命令”时，需要安装 Node.js，
并在安装后重新打开终端或重启面板。

## 报错找不到浏览器

Windows 安装 Chrome 或 Edge，`rules.browser` 先保持空字符串。Linux 面板服安装
Chromium 后，在 `rules.browser` 填服务商提供的可执行文件路径。

## 玩家无法加入

检查：

- CraftEngine 和 BetterHUD 是否正常启用；
- 是否安装 GSit 或 CMI；
- 玩家是否有 `sanguo.play`；
- 牌桌是否已经开始或坐满；
- 经济桌余额是否足够；
- 玩家是否已经坐在另一张桌。

## 牌、武将或按钮显示方框

这是资源包问题，不是 Noname 规则问题：

1. CraftEngine 的两个 Sanguo 资源目录是否完整；
2. CraftEngine 是否成功构建资源包；
3. 客户端是否接受并加载资源包；
4. 服务端是否完整重启。

## 准星没有说明

这是 BetterHUD 链路：

- 检查三个 BetterHUD 子目录是否已合并；
- 检查 `crosshair_text_hud` 是否加入服主使用的 HUD；
- 看 BetterHUD 控制台是否有格式错误；
- 执行 `/sanguo reload` 后重新加入牌桌。

## 选中牌又弹回

- 看 Actionbar 是否要求选择角色；
- 检查目标是否在距离内；
- 确认当前是自己行动；
- 无中生有、装备、闪电不需要选其他角色；
- 杀、顺手牵羊等需要合法目标。

如果按钮全部消失且双方一直等待，保存控制台从卡住前 30 秒到卡住后的日志，并记录：

- 牌名；
- 当前玩家武将；
- 点击顺序；
- 真人数量和 AI 数量。

## 黄盖苦肉后要求弃牌

技能点击后应直接失去 1 点体力并摸 2 张。如果是在**回合结束前**进入弃牌阶段，
通常是因为手牌超过降低后的体力上限，属于正常规则；标准黄盖本身没有弃牌步骤。

## 铁索连环怎么重铸

先点“重铸”，再选铁索连环，最后确定。先选择铁索连环会进入普通使用流程。

## 经济被冻结

不要删除 `wager-transactions.log`。对照 Vault/PlayerPoints 流水，核对悬空
`INTENT` 或没有 `MATCH_CLOSED` 的局，再人工处理。

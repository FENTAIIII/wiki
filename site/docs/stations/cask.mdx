# 小木桶

小木桶用来**发酵**：酒、果酒、蜜酒之类。它不需要热源，但**怕光**——放在暗处发酵快得多。

## 基本用法

1. 放置小木桶。
2. **右键**打开界面，把材料放进 **4 个输入格**。
3. 满足配方后自动开始发酵，界面上会显示气泡与光照状态。
4. 完成后成品出现在**输出格**，取出即可。

界面共 27 格，包含 4 个输入格、1 个输出格、进度气泡与一个光照指示灯，另有配方书按钮可以直接翻阅木桶配方。

## 光照决定速度

这是小木桶最关键的机制。发酵速度按**天空光照**分三档：

| 天空光照 | 速度倍率 | 说明 |
| --- | --- | --- |
| 0–5（黑暗） | **2 倍** | 最快，推荐 |
| 6–10（昏暗） | 1 倍 | 正常 |
| 11 以上（明亮） | **0.5 倍** | 最慢，慢一半 |

界面里的**指示灯**会显示当前处于哪一档，颜色越暗越好。

:::tip[建个酒窖]
把小木桶放在地下、山洞里或封闭的室内，天空光照为 0，发酵速度直接翻倍。注意判定的是**天空光照**，火把不会拖慢速度。
:::

## 发酵时间

每条配方各自定义时间，范围 1–600 秒，另外给一定经验。实际耗时要再乘上光照倍率：

- 在黑暗处：配方时间 ÷ 2
- 在明亮处：配方时间 × 2

## 常见产物

小木桶主要产出暖风丰年的酒类与饮品：甜浆果酒、樱桃酒、蓝莓酒、发光浆果酒、西瓜酒、蜜酒、红葡萄酒、绿葡萄酒、覆盆子酒、硬苹果酒、私酿酒、根汁汽水等。

完整列表用游戏内 `/ng cask recipes` 查看。

## 与木盆的区别

| | 小木桶 | 木盆 |
| --- | --- | --- |
| 驱动方式 | 时间自动发酵 | 玩家踩踏 |
| 影响速度 | 天空光照 | 踩踏频率、人数 |
| 产出方式 | 输出格取出 | 装瓶或直接给予 |
| 典型产物 | 酒类 | 果汁、酒基、油 |

通常流程是**先用木盆踩出果汁或酒基，再用小木桶发酵成酒**。

## 注意事项

- 界面里的材料在区块卸载后依然保留，发酵进度会暂停而不丢失。
- 破坏小木桶会掉落里面的物品。

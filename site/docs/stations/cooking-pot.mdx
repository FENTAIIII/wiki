# 烹饪锅

烹饪锅是产出最丰富的设备：汤、炖菜、意面、寿司、果酱、饮品几乎都靠它。

## 基本用法

1. 把烹饪锅放在**点燃的炉灶**（或其他[热源](/stations/overview#什么算热源)）上。
2. **右键**打开烹饪锅界面。
3. 把**食材**放进左上方的 6 个输入格。
4. 如果配方需要容器（碗、玻璃瓶、罐子等），把容器放进**容器格**。
5. 满足配方后自动开始烹饪，界面上会显示火焰与进度。
6. 完成后成品出现在**输出格**，取出即可。

界面共 27 格，其中：

- **6 个食材格**：一次最多放 6 种不同食材。
- **1 个容器格**：碗、瓶、罐等。
- **1 个输出格**：成品。
- 火焰、进度条为显示用，不能放东西。
- 界面里还有一个**配方书按钮**，点击可以直接翻阅烹饪锅配方。

:::note 没有火焰就不会煮
如果界面里看不到火焰，说明下方没有有效热源。检查炉灶是否已经点燃。
:::

## 烹饪时间与经验

每条配方各自定义时间与经验。常见档位：

| 时间 | 典型配方 |
| --- | --- |
| 5 秒 | 米饭、焦糖、华夫饼、巧克力棒 |
| 10 秒 | 热可可、饺子、各种汤与炖菜、寿司 |
| 16 秒 | 默认值：三明治、汉堡、面团、曲奇 |
| 20 秒 | 果酱、玉米饼、通心粉、填馅南瓜 |

经验一般在 0.1 到 2.0 之间。烹饪时间上限为 600 秒。

## 可替换食材

很多配方的某一格接受多种等价食材，例如：

- **卷心菜**格接受卷心菜或卷心菜叶。
- **奶类**格接受牛奶瓶、原版奶桶或山羊奶瓶。
- **奶酪**格接受切达奶酪轮或山羊奶酪轮。
- **葡萄**格接受红葡萄或绿葡萄。
- **熟肉**格接受牛排、熟鸡肉、熟猪排、熟羊肉、熟兔肉或熟香肠。
- **鱼片**格接受鲑鱼片或鳕鱼片。

游戏内 `/ng recipes` 的配方详情会显示每一格的全部候选。

## 三种外观

烹饪锅会根据下方热源**自动切换外观**，功能完全相同：

| 热源 | 外观 |
| --- | --- |
| 炉灶、火 | 普通烹饪锅 |
| 点燃的营火 | 带挂柄烹饪锅 |
| 岩浆 | 带托盘烹饪锅 |

## 金烹饪锅（末地乐事）

金烹饪锅 `endersdelight:cooking_pot_gold` 的界面是金色的，并且是**部分末地料理的唯一制作途径**。

<RecipeFor item="endersdelight:cooking_pot_gold" />

- 标记为「仅金锅」的配方共 **11 条**（填馅潜影贝、紫颂炖、缠怨麦片、末影螨炖、珍珠意面、末影海鲜饭、琥珀竹荪炖、琥珀竹荪咖喱、鸡肉咖喱、牛排配薯条、竹荪烩饭）**只能用金烹饪锅做**，普通烹饪锅不接受这些配方。在配方浏览器里它们显示为金色界面。
- 反过来，普通配方在金锅里也能做。
- 这些末地配方通常需要**潜影贝碗** `endersdelight:shulker_bowl` 作为容器。

## 大餐方块

部分成品是**大餐方块**（整只烤鸡、填馅南瓜、蜜汁火腿、牧羊人派、寿司拼盘、微光沙拉），放在地上可以被多人反复取食，适合团队补给。

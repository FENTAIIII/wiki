# 砧板

砧板不需要热源，是最早期就能用上的加工设备。它的作用是**把一份材料切成多份产物**，比如把生牛肉切成牛肉馅、把原木剥成树皮、把作物切成食材。

服务器还支持 **49 种木种砧板**（`zhanban:*`）。它们功能完全相同，只是外观不同，是否可用取决于服务器有没有装对应资源包。

## 基本用法

砧板没有界面，全靠右键：

1. **手持材料右键**砧板 → 材料放到砧板上（可以多次右键叠加同一种材料）。
2. **手持工具右键**砧板 → 切割一份，产物掉落在砧板前。
3. **空手右键**砧板 → 把没切的材料拿回来。

要点：

- 每次切割只消耗**一份**材料。砧板上叠了 16 份就要右键 16 次。
- 产物是**掉落在地上**的，不会进背包，记得捡。
- 切割成功会消耗工具**一点耐久**。
- 砧板上只能放**同一种**材料。

## 工具类别

每条砧板配方规定了需要什么工具，共四类：

| 类别 | 含义 |
| --- | --- |
| `knife` | 任意刀具（五种整合刀具都行）——绝大多数配方 |
| `axe` | 任意原版斧——剥树皮之类 |
| `shovel` | 任意原版铲——黏土、沙砾之类 |
| `none` | 只接受配方指定的特定工具 |

配方还可以额外指定最多 6 个**特定工具**，与上面的类别是「或」关系：满足类别或持有指定工具之一都能切。

:::tip
拿不准就用刀。绝大多数配方是 `knife`，而刀在游戏内 `/ng cut recipes` 的配方详情里会直接显示出来。
:::

## 概率产出

砧板配方的每个产物都有独立**概率**。例如切某些作物时，主产物 100% 掉落，附带的种子可能只有一定概率掉落。游戏内配方详情会显示概率。

## Farmers Delight 配方包

插件内建 **61 条** `fd-*` 前缀的 Farmers Delight 砧板配方，覆盖树皮、竹篮、黏土与沙砾、稻穗、熟肉、野生作物、花朵染料等。

这些配方**不会自动启用**，需要管理员执行一次：

```
/ng recipes import-farmers-delight
```

该命令只补充缺失的条目，不会覆盖已有配方。详见[管理员命令](/admin/commands)。

## 刀具的额外用途

用整合内容的刀**击杀生物**会有额外掉落：

- 击杀未着火的**猪**：50% 掉落火腿，抢夺每级 +10%。
- 击杀**着火的猪**：掉落烟熏火腿。
- 击杀**疣猪兽**：必定掉落对应火腿。

这不会改变原版掉落，也不消耗刀具耐久。

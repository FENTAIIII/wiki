# 煎锅

煎锅是最简单的烹饪设备：没有界面，手持食材右键就能煎。但它有**翻面机制**，不翻会糊。

## 基本用法

1. 把煎锅放在**点燃的炉灶**（或营火、岩浆等[热源](/stations/overview#什么算热源)）上。
2. **手持食材右键**煎锅放入。可以多次右键叠加同一种食材，最多放到该物品的一组上限。
3. 等待烹饪完成，默认 **10 秒**。
4. **空手右键**取出成品。完成时给触发烹饪的玩家 **0.35** 点经验（具体数值随配方而定）。

放入的食材必须有对应的煎锅配方，否则右键没有反应。锅里已有食材时只能继续放**同一种**食材。

## 翻面：别让食材糊掉

这是煎锅最容易踩的坑：

- 食材受热超过总烹饪时长的 **70%** 还没翻过面，就会**烧焦**，直接变成一块木炭掉在地上。
- 也就是说**每份食材至少要翻一次面**。
- 快要糊的时候（受热到烧焦阈值的 60%）锅上会冒出**警告粒子**，看到就赶紧翻。

### 怎么翻面

**手持铲子右键**煎锅即可翻面。锅铲和原版铲子都可以。翻面时食材会跳起来翻滚。

翻面的好处不只是防糊：

- **重置烧焦计时**，让食材重新均匀受热。
- 额外推进 **30 tick（1.5 秒）**烹饪进度，也就是翻面能加速。

:::tip
理想操作是在进度到一半左右翻一次面：既避免烧焦，又白拿 1.5 秒进度。
:::

## 默认能煎什么

插件内建的煎锅配方包含全部原版生肉与几样蔬菜：

## 金煎锅系列（末地乐事）

金煎锅比普通煎锅快，但会**积油渍**逐级变慢，需要用**肥皂**清洗。

<RecipeFor item="endersdelight:skillet_gold" />


| 煎锅 | 每周期推进 | 说明 |
| --- | --- | --- |
| 金煎锅 `skillet_gold` | 8 tick | 最快 |
| 带油渍 `skillet_cracked` | 6 tick | 略慢 |
| 油污 `skillet_damaged` | 4 tick | 更慢 |
| 重油垢 `skillet_broken` | 0 | **无法使用**，只能回炉熔炼成 1 金锭 |
| 普通煎锅 `default:skillet` | 5 tick | 基准，不会积油渍 |

规则：

- 金煎锅**每累计煎熟 16 件成品自动降一档**（家具自动替换，正在煎的食物保留）。
- 用**肥皂右键**脏煎锅可以逆向清洗一档：重油垢 → 油污 → 带油渍 → 金煎锅。
- 金煎锅在**普通炉灶和末地石炉灶上都能用**；普通煎锅**不能**放在末地石炉灶上（不会加热）。

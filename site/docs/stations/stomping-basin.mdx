# 木盆

木盆是**用脚踩**的设备：放入水果，然后站上去踩，把果肉踩成液体，再用瓶子装出来。适合大批量做果汁与酒基。

## 基本用法

1. 放置木盆。
2. **右键**打开界面，把水果放进 **4 个输入格**。
3. **站到木盆上踩**——每次落到木盆上都算一次踩踏。
4. 踩够次数后消耗一份材料，盆里的**液体量**上升，界面上能看到液面。
5. 把**空瓶**（或配方要求的容器）放进界面的**装瓶格**，液体会自动装成成品交给你。

不需要热源，不需要点燃。

## 踩踏规则

- 每份材料默认需要踩 **5 次**（不同配方可以有不同值，范围 1–200）。
- 同一个玩家的踩踏有 **5 tick（0.25 秒）冷却**，不能靠原地抖动刷。
- 多个玩家可以**同时踩同一个木盆**，各自独立计冷却，人多显著更快。
- **飞行、滑翔、游泳、坐载具时不计**踩踏，必须是正常落到木盆上。

:::tip
踩踏是按「落下」判定的，站着不动不会计数。持续走动或反复跳跃最有效。
:::

## 液体与装瓶

- 木盆最多容纳 **1000 mB** 液体。装满后继续踩不再增加，需要先装瓶腾出空间。
- 每份材料产生的液体量由配方决定（1–1000 mB）。
- 装一瓶消耗的液体量也由配方决定（1–1000 mB）。
- 放入多个空瓶时会**一次装满能装的数量**：例如盆里 500 mB、每瓶 125 mB，放入 8 个空瓶会一次装出 4 瓶。
- 液体清空后木盆会重置，可以换做别的配方。

## 两类配方

**液体类**（`liquid-enabled`）：踩出液体，再用容器装瓶。绝大多数果汁与酒基走这条路。

**直接产出类**：踩够次数直接把成品塞给玩家，不经过液体阶段。例如：

- **粘液块分解**：粘液块 → 9 个粘液球。
- **湿海绵挤水**：湿海绵 → 水桶 + 海绵。

## 常见配方举例

| 成品 | 材料 | 说明 |
| --- | --- | --- |
| 苹果酒 | 苹果 | 液体类，玻璃瓶装 |
| 覆盆子汁 | 覆盆子 | 每份 125 mB，每瓶 500 mB |
| 食用油 | 番茄种子 / 南瓜种子等 8 个 | 液体类 |
| 粘液块分解 | 粘液块 | 直接产出 9 个粘液球 |
| 湿海绵挤水 | 湿海绵 | 直接产出水桶 |

完整列表用游戏内 `/ng stomping recipes` 查看。

## 注意事项

- 换配方前最好把液体装完。盆里还有液体时切换材料不会立即生效。
- 界面里放入的材料在区块卸载后依然保留，进度不会丢。
- 破坏木盆会掉落里面的物品。

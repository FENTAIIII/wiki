# 炉灶

炉灶是整个厨房的核心：它既是烹饪锅与煎锅的**热源**，灶面本身也能**直接烤肉**。

## 点燃

炉灶放下来时是熄灭状态，需要**手持打火石右键**点燃。点燃后打火石会损耗一点耐久。

- 已经点燃的炉灶再右键不会有反应，也不会浪费耐久。
- 炉灶点燃状态会被记录下来，服务器重启或区块重新加载后依然保持点燃。

### 末地石炉灶

末地乐事的末地石炉灶（`endersdelight:endstone_stove`）规则不同：

<RecipeFor item="endersdelight:endstone_stove" />

- 必须用**龙息**点燃，不是打火石。点燃后消耗一份龙息。
- 燃烧时是**紫色火焰**而不是橙色。
- 它是「高级炉灶」：**只接受金煎锅系列**，普通煎锅放上去不会被加热。金煎锅在普通炉灶和末地石炉灶上都能用。
- 用龙息点燃它会解锁「末地乐事」成就页的**紫焰燃起**。

## 灶面烤肉

点燃的炉灶顶部可以直接放食物烤，不需要任何容器或界面。

- 灶面共有 **6 个位置**，可以同时烤 6 份食物。
- 手持食物**右键炉灶顶部**放入一份，食物会以模型形式显示在灶面上。
- 烤好后**右键取出**。
- 灶面烤肉**复用煎锅配方**，能煎的东西就能在灶面上烤。
- 与煎锅不同，灶面烤肉**不给经验**。

:::tip
灶面烤肉是无人值守的：即使区块卸载，进度也会暂停而不会丢失食物，区块加载回来后继续烤。
:::

## 作为热源

把**烹饪锅**或**煎锅**放在点燃的炉灶上（同一格或正上方一格），设备就会开始工作。

烹饪锅还会根据热源类型自动切换外观：

| 热源 | 烹饪锅外观 |
| --- | --- |
| 炉灶、火 | 普通烹饪锅 |
| 点燃的营火 | 带挂柄烹饪锅 |
| 岩浆 | 带托盘烹饪锅（岩浆版） |

外观切换是自动的，不影响配方与速度。
